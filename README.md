# Raycast RU

Неофициальный русский перевод интерфейса [Raycast](https://www.raycast.com) 2.x для macOS.

*Unofficial Russian localization for Raycast 2.x on macOS.*

Raycast не поддерживает русский язык. Начиная с версии 2.x его интерфейс работает на веб-технологиях. Этот проект подключает к окнам Raycast небольшой скрипт: он на лету заменяет английский текст на русский по словарю. Сама программа и её данные не меняются, удаление возвращает всё как было.

- Около 5600 переведённых строк: настройки, лаунчер, панель действий, AI-чат, заметки, буфер обмена, управление окнами, уведомления и ошибки.
- Шаблоны для строк с числами: «5 мин назад», «Сегодня в 10:00», «Элементов: 3».
- Проверено на Raycast 2.6.0.

## Установка

```bash
git clone https://github.com/Yosikava/raycast-ru.git ~/raycast-ru
~/raycast-ru/install.sh
```

Затем полностью перезапустите Raycast: значок в строке меню → Quit Raycast, затем запустите снова.

macOS может попросить разрешить терминалу «Управление приложениями» (App Management). Без этого разрешения скрипт не сможет записать файлы в `Raycast.app`.

Если Raycast установлен не в `/Applications`, укажите путь:

```bash
APP=~/Applications/Raycast.app ~/raycast-ru/install.sh
```

### После обновления Raycast

Обновление заменяет файлы приложения, поэтому перевод пропадает. Запустите `install.sh` ещё раз и перезапустите Raycast.

## Удаление

```bash
~/raycast-ru/uninstall.sh
```

## Как это работает

`install.sh` копирует два файла в `Raycast.app/…/frontend/` и подключает их в каждом HTML-окне:

- `src/ru-dict.js` — словарь. Собирается из `tr/ru.tsv`, руками его не правят.
- `src/ru-translate.js` — переводчик. Он обходит страницу и следит за изменениями через `MutationObserver`. Переводит текст и атрибуты `placeholder`, `title` и `aria-label`. Поля ввода, редактируемый текст и блоки кода не трогает. Строки, которых нет в словаре, сохраняет в `localStorage` окна. Наружу ничего не отправляется.

## Как помочь с переводом

Все переводы лежат в одном файле `tr/ru.tsv`. Каждая строка выглядит так: английская строка, символ TAB, русский перевод. Перенос строки внутри текста записывается как `\n`.

1. Найдите непереведённое:
   - `python3 tools/misses.py` — строки, которые вы видели в Raycast, но которых нет в словаре. В список могут попасть ваши данные, например имена файлов. Их пропускайте.
   - `python3 tools/extract.py` — строки из установленного Raycast, которых нет в словаре. Удобно после обновления Raycast.
2. Допишите переводы в `tr/ru.tsv`.
3. Соберите словарь и установите:

   ```bash
   python3 tools/build_dict.py
   ./install.sh
   ```

4. Перезапустите Raycast.

Шаблоны для строк с числами лежат в `tr/patterns.json`. Каждый шаблон — пара «регулярное выражение — замена», где `$1` подставляет найденную группу.

`tools/test.html` — тестовая страница для проверки переводчика в браузере.

## Ограничения

- Поиск команд работает по английским названиям. Перевод меняет только то, что видно на экране, поэтому «История буфера обмена» находится по запросу «clipboard».
- Тексты сторонних расширений переводятся, только если совпадают со строками словаря.
- Системные элементы macOS (меню приложения, стандартные диалоги) не переводятся.
- Обновление Raycast может переименовать строки. Тогда часть интерфейса снова станет английской, пока словарь не обновят.
